# Resources 폴더

이 폴더는 iOS와 Android에서 공통으로 사용할 아이콘과 스플래시 이미지를 저장하는 곳입니다.

## 필요한 파일

다음 파일들을 이 폴더에 넣어주세요:

### 1. 아이콘 (Icon)
- **파일명**: `icon.png`
- **크기**: 1024x1024 픽셀 (정사각형)
- **형식**: PNG (투명 배경 가능)
- **설명**: 앱 아이콘으로 사용됩니다.

### 2. 스플래시 (Splash)
- **파일명**: `splash.png`
- **크기**: 2732x2732 픽셀 (정사각형, 권장)
- **형식**: PNG
- **설명**: 앱 시작 시 표시되는 스플래시 화면입니다.

## 파일 배치 후 작업

파일을 넣은 후 다음 명령어를 실행하여 각 플랫폼에 적용할 수 있습니다:

```bash
# Capacitor Assets를 사용하는 경우 (설치 필요)
npm install -D @capacitor/assets
npx capacitor-assets generate

# 또는 수동으로 복사하는 스크립트를 실행
```
